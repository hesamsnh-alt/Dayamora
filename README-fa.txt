اصلاح دکمه ثبت درخواست سفارش — دایامورا

این پچ فقط فایل public/app.js را بر اساس نسخه آنلاین بررسی‌شده در ۲۲ اکتبر ۲۰۲۶ اصلاح می‌کند. امکانات رنگ و سایز و پرداخت نسخه آنلاین در آن حفظ شده‌اند. فایل دیتابیس و تنظیمات اتصال تغییر نمی‌کنند.

مشکل پیدا شده: پیام خطا در toast خارج از dialog سبد نمایش داده می‌شد و پنجره سبد آن را می‌پوشاند. اکنون نتیجه و خطا در خود سبد ظاهر می‌شوند، هنگام ارسال دکمه وضعیت در حال ثبت دارد و پس از خطا دوباره فعال می‌شود. اگر پیام سرور مربوط به آدرس یا شماره تماس باشد، لینک تکمیل مشخصات در باشگاه نمایش داده می‌شود.

در قطع ارتباط، سبد حفظ می‌شود و کلید همان درخواست برای تلاش دوباره حفظ می‌شود. ابتدا سفارش‌های باشگاه را بررسی کنید تا وضعیت درخواست قبلی روشن شود. در پاسخ موفق، کد سفارش و لینک پیگیری نمایش داده می‌شود. پچ خطاهای واقعی سرور مانند ناموجودی یا ناقص‌بودن مشخصات را مخفی یا نادیده نمی‌گیرد.

نصب:
۱. از فایل public/app.js فعلی یک کپی بیرون از پوشه پروژه نگه دارید.
۲. محتویات این ZIP را داخل پوشه اصلی Dayamora، کنار package.json کپی و Replace کنید؛ فایل app.js داخل public قرار دارد، نه app.js قدیمی ریشه.
۳. در ترمینال VS Code:

git add public/app.js
git commit -m "Fix visible checkout errors and order submission feedback"
git push origin main

پس از موفقیت Deploy در Netlify، صفحه را دوباره بارگذاری کنید و یک بار ثبت سفارش را بزنید. اگر اطلاعات تماس ناقص است، از لینک تکمیل مشخصات استفاده کنید.

بررسی انجام‌شده: سینتکس فایل و چهار سناریوی خطای مشخصات، شکست ذخیره سبد، قطع ارتباط و حفظ کلید درخواست، پاسخ موفق و جلوگیری از دوبار ارسال. سفارش واقعی روی حساب کاربر در سایت ثبت نشده است؛ خطای احتمالی دیتابیس یا موجودی پس از نصب، در خود سبد قابل مشاهده خواهد بود.
