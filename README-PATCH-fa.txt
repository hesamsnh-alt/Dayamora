پچ برش دستی و بررسی پیش‌نویس دایامورا

این بسته شامل اصلاحات پچ‌های قبلی مجله، مشتریان، واردکننده و تشخیص خطای ترجمه است. از پروژه فعلی پشتیبان بگیر؛ فایل‌های ZIP را در ریشه پروژه کنار package.json کپی و جایگزین کن. پوشه‌ها باید ادغام شوند.

دستورها در ترمینال VS Code:
npm ci
npm test
npm run build
git add .
git commit -m "Add manual crop and validate imported drafts"
git push origin main
سپس نسخه جدید را در Netlify دیپلوی کن. هیچ پوش یا دیپلوی از طرف ما انجام نشده است.

اصلاحات:
- برش دستی روی خود عکس با کشیدن کادر، جابه‌جایی داخل کادر و کشیدن گوشه‌ها؛ با لمس یا ماوس. کادرهای درصدی قبلی حذف شده‌اند.
- در واردکننده، کنار هر عکس «برش عکس» هست. در فرم اصلی محصول «برش دستی عکس» هست و بعد از انتخاب عکس جدید، ابزار باز می‌شود. «اعمال برش» نتیجه را روی پیش‌نمایش می‌گذارد؛ ذخیره واقعی با ثبت محصول است. انصراف اصل تصویر را حفظ می‌کند.
- فیلدها و ستون‌های فرم برای جلوگیری از بیرون‌زدگی افقی اصلاح شده‌اند.
- پیش‌نویس خودکار ترجمه‌نشده یا بدون عکس، به فرم تأیید نهایی منتقل نمی‌شود. اطلاعات ناقص و علتش مشخص می‌شوند.
- «تلاش دوباره برای ترجمه فارسی» اضافه شده؛ عکس‌ها دوباره دانلود نمی‌شوند.
- کیف با دستهٔ پیش‌فرض پوشاک وارد نمی‌شود. دستهٔ ناشناخته نیازمند انتخاب است.
- سایز و رنگِ دریافت‌نشده از منبع، با اطلاعات ساختگی جایگزین نمی‌شوند؛ پیام نبود اطلاعات نمایش داده می‌شود.
- خطاهای کلید، اعتبار، سهمیه، نرخ درخواست و مدل ترجمه جدا نمایش داده می‌شوند.

محدودیت حل‌نشده:
این پچ تأیید عملکرد کامل لینک واقعی Temu شما نیست. علت شکست ترجمهٔ زنده هنوز از اسکرین‌شات مشخص نشده است. بعد از دیپلوی، بررسی لینک را دوباره بزن و متن کد OPENAI_... را گزارش کن؛ کلید را در چت نفرست.
ترجمه نیازمند OPENAI_API_KEY در متغیرهای سرور Netlify است. متغیر اختیاری DAYAMORA_IMPORT_TRANSLATION_MODEL پیش‌فرض gpt-4o-mini دارد. کلید در گیت یا فایل عمومی قرار نگیرد.
اگر Temu رنگ، سایز یا عکس‌ها را در پاسخ عمومی منتشر نکند، دریافت کامل آن‌ها تضمین نمی‌شود. ارتباط عکس و رنگ فقط از رابطه‌ای که منبع مشخص کرده حفظ می‌شود؛ حدس زده نمی‌شود.
برش، حذف پس‌زمینه یا جداکردن لباس از بدن نیست. قیمت، موجودی و ارسال باید مطابق قواعد فروشگاه تعیین شوند.

بررسی:
۶۹ تست موفق، یک تست محیطی اجرا نشده، build موفق. در مرورگر با داده ساختگی، جلوگیری از انتقال ترجمه ناموفق بررسی شد. کشیدن گوشهٔ کادر، عکس ۳۲۰×۳۲۰ را به خروجی ۲۳۷×۲۳۴ برش داد. در نمای بررسی‌شده، عرض محتوای فرم برابر عرض فرم بود و اسکرول افقی نداشت.
این بررسی جای تست ترجمهٔ واقعی و محصول واقعی را نمی‌گیرد. هیچ تغییری در ساختار یا اطلاعات دیتابیس و تنظیم حساب‌های خارجی انجام نشده است. db:init اجرا نکن. مجله و راهنمای سایز و ابزار مشتری حفظ شده‌اند.
