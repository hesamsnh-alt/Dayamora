پچ آماده‌سازی خودکار محصول و ترجمه فارسی — دایامورا
این بسته همه اصلاحات پچ قبلی مجله و ابزار مشتری را هم دارد؛ لازم نیست بسته قبلی را دوباره نصب کنید. مبنا dayamora4.zip و پچ قبلی آن است. هیچ تغییر ساختار دیتابیس، پوش گیت یا دیپلوی انجام نشده است.

نصب:
از پوشه فعلی پروژه کپی پشتیبان بگیر. فایل‌های این بسته را در ریشه پروژه کنار package.json کپی و جایگزین کن؛ پوشه‌ها باید ادغام شوند.
در ترمینال VS Code:
npm ci
npm test
npm run build
git add .
git commit -m "Automate product photos, Persian translation and draft review"
git push origin main
سپس نسخه تازه را در Netlify دیپلوی کن.

ترجمهٔ واقعی:
این قابلیت به سرویس OpenAI متصل شده و بدون کلید فعال نیست. در متغیرهای سرور پروژه Dayamora در Netlify تنظیم کن:
OPENAI_API_KEY = کلید API حساب خودت
DAYAMORA_IMPORT_TRANSLATION_MODEL = gpt-4o-mini
متغیر دوم اختیاری است؛ مدل پیش‌فرض همین است. کلید باید امکان استفاده از API و اعتبار لازم را داشته باشد. کلید را در چت، فایل عمومی سایت یا گیت قرار نده. بعد از تنظیم متغیر، دیپلوی تازه لازم است. این پچ خودش کلید، حساب یا اعتبار خریداری نکرده و درخواست واقعی ترجمه پولی اجرا نکرده است.
نام، توضیح، رنگ‌ها و برچسب‌های توصیفی سایز با خروجی ساختاریافته به فارسی ترجمه می‌شوند. نام رسمی برند، اندازه‌ها، واحدها و کدهای M/L/XL و مدل حفظ می‌شوند. کلید فقط در سرور استفاده می‌شود؛ متن منبع دادهٔ غیرقابل اعتماد محسوب می‌شود، ابزار خارجی در اختیار مدل نیست و پاسخ باید اعتبارسنجی شود.

کارکرد:
پنل مدیریت ← محصولات ← ورود محصول از لینک ← چسباندن لینک و «بررسی لینک».
۱. اطلاعات عمومی همان محصول استخراج می‌شوند؛ محصولات پیشنهادی نامرتبطِ داخل داده ساختاریافته با محصول مخلوط نمی‌شوند.
۲. ترجمه و دریافت خودکار عکس‌ها شروع می‌شوند. دیگر لازم نیست تک‌تک عکس‌ها را برای دریافت کلیک کنی. وضعیت پیشرفت نمایش داده می‌شود.
۳. عکس‌ها با حفظ تناسب و بدون بزرگ‌نمایی تصاویر کوچک، تا ضلع بزرگ ۱۸۰۰ پیکسل آماده و در فضای آپلود موجود فروشگاه ذخیره می‌شوند.
۴. اگر منبع ارتباط رنگ و عکس را در داده ساختاریافته مشخص کرده باشد، همان عکس برای همان رنگ در پیش‌نویس و فرم نهایی ذخیره می‌شود. نمونه‌رنگ نمایشی تقریبی است؛ مشخصه قطعی رنگ محصول نیست.
۵. تا ۲۹ عکس شامل گالری و عکس رنگ‌ها آماده می‌شود؛ مطابق ساختار موجود، عکس اصلی و هشت عکس تکمیلی در گالری قرار می‌گیرند و عکس‌های اختصاصی رنگ‌ها جدا حفظ می‌شوند.
۶. پیش‌نویس خودکار در جدول موجود product_imports ذخیره می‌شود. محصول بدون تأیید مدیر منتشر نمی‌شود. از «پیش‌نویس‌های لینک» می‌توان دوباره آن را باز کرد.
۷. مدیر اطلاعات آماده را بررسی می‌کند، در صورت نیاز برش عکس را اصلاح می‌کند و به فرم نهایی تأیید محصول می‌رود. برش دستی با پیش‌نمایش از قبل موجود و حفظ شده است. تغییرات پیش‌نویس روی همان رکورد ذخیره می‌شوند، نه رکورد تکراری.
۸. قیمت فروش تومان، موجودی و هزینه ارسال همچنان از قواعد فروشگاه باید تعیین شوند. نرخ ارز، سود و موجودی از طرف برنامه ساخته نمی‌شوند. نام/عکس/رنگ و توضیح خودکار، به‌تنهایی به معنی قیمت‌گذاری و موجودی‌گذاری خودکار نیست.

محدودیت‌های واقعی:
- بدون OPENAI_API_KEY ترجمه کامل نمی‌شود؛ خطای روشن نمایش داده می‌شود و پیش‌نویس خودکارِ ترجمه‌نشده قابل تأیید برای انتشار نیست. پس از فعال‌کردن سرویس، لینک را دوباره بررسی کن.
- بدون دسترسی مبدأ، داده‌ای برای استخراج وجود ندارد. Temu و Amazon ممکن است صفحه، تصاویر یا تنوع رنگ را برای دریافت خودکار محدود کنند یا فقط پس از اجرای جاوااسکریپت نمایش دهند. این پچ دورزدن محدودیت آن‌ها یا اتصال رسمی فروشنده ندارد. دریافت کامل از لینک Temu ارسال‌شده در این محیط تأیید نشده است.
- اگر ارتباط عکس و رنگ در منبع مشخص نباشد یا دانلود عکس شکست بخورد، برنامه آن ارتباط را حدس نمی‌زند؛ موردِ نیازمند بررسی نمایش داده می‌شود. گالری عمومی به‌دلخواه به رنگ‌ها نسبت داده نمی‌شود.
- ترجمهٔ معتبر از نظر قالب، تضمین صحت صددرصد محتوای زبانی نیست؛ تأیید مدیر همچنان لازم است.
- حذف پس‌زمینه، جداکردن لباس از بدن شخص، تغییر رنگ تصویر یا تولید عکس جدید انجام نمی‌شود. عکس محصول حفظ می‌شود.
- خرید از فروشنده مبدأ یا همگام‌سازی خودکار قیمت/موجودی انجام نمی‌شود.

بخش‌های قبلی:
لینک مدیریت مجله و API مجله، ساخت حساب مشتری و لینک خصوصی تعیین رمز، ثبت‌نام دومرحله‌ای و بازیابی رمز پچ قبلی حفظ شده‌اند. ارسال ایمیل بازیابی همان تنظیم مستقل RESEND_API_KEY و DAYAMORA_MAIL_FROM را لازم دارد؛ لینک دستی مدیر مستقل از سرویس ایمیل است.
طراحی سایر صفحات، راهنمای سایز، مانکن، سفارش‌ها و پروژه‌های دیگر تغییر نکرده‌اند. هیچ مهاجرت جدید یا تغییر ساختار دیتابیس لازم نیست؛ db:init اجرا نکن.

بررسی:
۶۳ تست موفق، یک تست محیطی اجرا نشده؛ build موفق. ترجمه، ثبات شناسه رنگ، حفظ سایزهای استاندارد، ارتباط رنگ/عکس، دانلود و ذخیره خودکار و نبود انتشار خودکار تست شده‌اند. رابط با داده ساختگی در مرورگر بررسی شد. ترجمه با کلید واقعی و ایجاد محصول در دیتابیس زنده آزمایش نشده است.
