پچ لوگوی برندهای دایامورا

مبنا: کامیت 64d24e1 مخزن Dayamora، Fix brand display and remove duplicate brand names
این پچ روی نسخه فعلی برندها ساخته شده است. پچ‌های آزمایشی قدیمی برند را همراه آن نصب نکنید.

۳ فایل نمایشی اصلاح می‌شوند:
public/brand-catalog.js
public/style.css
public/discover.css
به‌علاوه فایل‌های SVG در public/assets/brand-logos قرار می‌گیرند.

فهرست موجود ۱۰۵ برند حفظ شده است. برای ۷۰ برند فایل لوگو بسته‌بندی شده است.
برای ۳۵ برند باقی‌مانده و برندهای اختصاصی جدید، نام کامل نمایش داده می‌شود؛ لوگوی ساختگی یا عکس خراب نشان داده نمی‌شود.
این بسته ادعا نمی‌کند که همه نسخه‌های لوگو جدیدترین بازطراحی هر برند هستند.
منبع هر فایل و فهرست لوگوهای موجود در brand-logo-sources.json ثبت شده است.
لوگوها متعلق به صاحبان همان علائم هستند؛ درج نام یا لوگو به معنی نمایندگی یا موجودی محصول نیست.

فایل‌ها را داخل پوشه اصلی پروژه، کنار package.json استخراج کنید و فایل‌های هم‌نام را جایگزین کنید.
پوشه پروژه را حذف نکنید. فایل‌های .env و دیتابیس تغییر نمی‌کنند.
سپس در ترمینال VS Code:
npm run build
git add public/brand-catalog.js public/style.css public/discover.css public/assets/brand-logos brand-logo-sources.json
git commit -m "Bundle local brand logos"
git push origin main

در پنل محصول، برند اختیاری فعلی حفظ شده است. برای اتصال محصول به برند، نام صحیح برند را در همان فیلد انتخاب یا وارد کنید.
برای کالای بدون برند، آن فیلد را خالی بگذارید و دسته مناسب را جداگانه انتخاب کنید.
این پچ محصول یا دسته‌بندی را از روی عکس یا اسم حدس نمی‌زند و اطلاعات موجود محصولات را تغییر نمی‌دهد.

بررسی: فایل‌های محلی SVG و نگاشت آدرس‌ها بررسی شد، نمایش کارت‌ها در مرورگر محلی و پنهان‌شدن نوشته تکراری بررسی شد؛ ۳۲ تست موفق و یک تست ابری قدیمی اجرا نشد؛ build موفق بود.
انتشار Netlify و push خودکار انجام نشده است.
