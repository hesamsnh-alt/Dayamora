پچ کامل سئوی دایامورا همراه معرفی تصاویر به Google Images

این نسخه جایگزین پچ سئوی قبلی است و تمام فایل‌های آن را دارد؛ لازم نیست هر دو را نصب کنید. بر مبنای نسخه دارای پچ آماده‌سازی خودکار مانکن و اصلاح تکمیلی صف است. اگر در چت دیگر یا روی کامپیوتر تغییر جدیدی داده‌اید، ابتدا اختلاف فایل‌ها را بررسی کنید تا تغییر جدیدتان حذف نشود. از پروژه بکاپ بگیرید و فایل‌ها را کنار package.json جایگزین کنید؛ کل پروژه را حذف نکنید.

پس از Published شدن نسخه در Netlify:
۱. https://dayamora.com/sitemap.xml را باز کنید. باید XML معتبر ببینید. داخل آن image:image و image:loc برای عکس‌های عمومی محصولات وجود دارد. اگر حجم زیاد باشد sitemap index می‌بینید و تصاویر داخل نقشه‌های فرعی هستند.
۲. در https://search.google.com/search-console با حساب گوگل خود Domain property با مقدار dayamora.com بسازید.
۳. TXT اختصاصی google-site-verification را در DNS فعال دامنه اضافه کنید: نوع TXT، نام @، مقدار دقیق گوگل، TTL پیش‌فرض. DNS فعال ممکن است GoDaddy یا Netlify باشد؛ بستگی دارد nameserverها کجا هستند. هیچ A/CNAME/MX یا nameserver موجود را برای این کار حذف یا تغییر ندهید. Verify را بزنید و رکورد TXT را نگه دارید.
۴. در Sitemaps آدرس https://dayamora.com/sitemap.xml را Submit کنید.
۵. در URL Inspection لینک صفحه اصلی و یک صفحه محصول واقعی را Test live URL و Request indexing کنید. صفحه محصول را در https://search.google.com/test/rich-results هم بررسی کنید.
۶. پس از ایجاد داده کافی، در Performance نوع جست‌وجو را Image بگذارید تا نمایش و کلیک عکس‌ها بررسی شود. این گزارش را با Web قاطی نکنید. ایندکس فوری یا زمان معین تضمین نمی‌شود.

تغییرات سئوی پایه:
- عنوان و توضیحات فارسی و canonical با دامنه اصلی dayamora.com، Open Graph و Twitter.
- اطلاعات عمومی محصول و مقاله و فهرست مجله و فروشگاه در HTML اولیهٔ سمت سرور، با حفظ اسکریپت‌ها و امکانات تعاملی. محتوای جداگانه برای Googlebot تولید نمی‌شود.
- Product/Offer/BreadcrumbList/BlogPosting؛ برند فقط اگر ثبت شده؛ امتیاز فقط از نظرات واقعی. قیمت ذخیره‌شده تومان است و فقط در schema به ریال استاندارد IRR ضربدر ۱۰ می‌شود؛ قیمت یا دیتابیس تغییر نمی‌کند.
- sitemap پویا فقط از محصولات فعال واقعی، دسته‌های دارای محصول و مقاله‌های منتشرشده. نمونه‌ها، غیرفعال‌ها، پیش‌نویس و صفحات حساب وارد آن نمی‌شوند.
- noindex برای صفحات حساب و مدیریت و بازیابی رمز و صفحات فیلتر ترکیبی؛ robots مسیر API و فایل خصوصی را مسدود می‌کند، تصاویر عمومی محصولات را مسدود نمی‌کند.
- پاسخ واقعی 404 برای محصول/مقاله پیدا‌نشده و پاسخ 503 در خطای سرویس؛ خطا به شکل نقشه خالی موفق نمایش داده نمی‌شود.
- API عمومی برای سئو بدون انتقال کوکی/هدر کاربر فراخوانی می‌شود و داده حساب‌ها وارد HTML cacheشده نمی‌شود.

اضافه‌شده برای Google Images:
- عکس اصلی، تصاویر تکمیلی گالری و تصاویر واقعی رنگ‌های محصول با آدرس عمومی پایدار در image sitemap به صفحه همان محصول متصل می‌شوند. کاور مقاله منتشرشده هم معرفی می‌شود.
- عکس‌های تکراری حذف می‌شوند؛ فایل‌های خصوصی، data URL، دامنه نامعتبر و تصاویر محصولات غیرفعال/نمونه در sitemap نمی‌آیند.
- گالری و تصاویر رنگ‌ها علاوه بر schema، با تگ واقعی img و alt در HTML اولیه محصول قرار می‌گیرند. نام رنگ فقط اگر به همان عکس در محصول متصل باشد استفاده می‌شود؛ رنگ عکس حدس زده نمی‌شود.
- عکس یا محصول جدید پس از ذخیره و فعال‌بودن، بدون push مجدد وارد نقشه می‌شود؛ cache CDN تا حدود ۶۰ ثانیه تأخیر دارد. ایندکس گوگل زمان‌بندی مستقل دارد.
- نقشه بزرگ براساس تعداد URL و حجم UTF-8 قطعه‌بندی می‌شود تا تصاویر زیاد باعث عبور از حد حجم نقشه نشوند.

این پچ عکس‌ها را مستقیماً در حساب گوگل آپلود نمی‌کند؛ آن‌ها را برای کشف و بررسی گوگل آماده می‌کند. نمایش، رتبه و زمان ایندکس در اختیار گوگل است. Google Images با Google Shopping تفاوت دارد؛ این پچ به معنای تأیید Merchant Center یا پذیرش فروشگاه در Shopping نیست. شرایط Merchant Center و کشور/ارز مقصد باید جداگانه بررسی شوند.

هیچ API key جدید یا migration یا npm ci لازم نیست. اتصال دیتابیس و فضای ذخیره‌سازی فعلی باید درست بماند. این تغییر از سهمیه Functions و دیتابیس موجود برای HTML و نقشه سایت استفاده می‌کند. هیچ دیتابیس زنده یا پروژهٔ دیگری تغییر نکرده است.

اعتبارسنجی: ۱۱ تست اختصاصی SEO/Image Sitemap موفق؛ build با ۷۹ تست موفق. آزمایش محیط زنده Netlify، حساب Search Console و ایندکس واقعی گوگل انجام نشده است. کیفیت نام و توضیحات محصولات و عملکرد موبایل باید با داده واقعی بررسی و اصلاح شود؛ رتبه یا رشد کلیک تضمین نمی‌شود.

به‌روزرسانی برای جست‌وجوی نام برند:
عنوان اصلی صفحه و عنوان سئو به «دایامورا» اولویت می‌دهند. داده WebSite نام فارسی دایامورا و نام لاتین Dayamora را به دامنه اصلی متصل می‌کند. این نشانه‌های هویت برند است و تضمین رتبه یا نمایش با هر جست‌وجو نیست.

وضعیت Shopping:
طبق فهرست رسمی گوگل در زمان بررسی، امارات مقصد پشتیبانی‌شده است و ایران در فهرست مقصدهای پشتیبانی‌شده نیست. فارسی هم در فهرست زبان‌های Merchant Center نیست. بنابراین سایت فعلی صرفاً با sitemap یا schema آماده پذیرش Shopping نیست.
قبل از ساخت فید باید روشن شود فروش و تحویل واقعی داخل امارات دارید یا صرفاً سفارش برای ایران می‌گیرید. اگر فروش امارات واقعی است، اطلاعات فروشنده و شرایط فروش و ارسال و مرجوعی و صفحه محصول/پرداخت باید با فید و زبان/ارز پشتیبانی‌شده هماهنگ شوند. بدون مشخص‌شدن این موارد، فید Merchant منتشر یا حسابی ساخته نشده است. هیچ کشور، ارز یا مقصد ساختگی ثبت نمی‌شود.

آیکون و لوگوی دایامورا:
همان کلمه dayamora با بخش daya سرمه‌ای #29344f و mora صورتی #ed1687، داخل دایره سفید و با گوشه‌های شفاف ساخته شده است. نوشته در فایل SVG به مسیر برداری تبدیل شده تا وابسته به نصب فونت نباشد. نسخه PNG لوگو ۵۱۲، آیکون گوگل ۹۶، آیکون اپل ۱۸۰ پیکسل است و ICO چند اندازه دارد. کل کلمه در آیکون‌های بسیار کوچک خوانایی محدودی دارد.
تنظیم favicon به HTML صفحه اصلی و خروجی صفحات سئو اضافه شده و لوگوی سازمان هم به آدرس عمومی مشخص متصل است. لوگوی هدر یا سایر قسمت‌های طراحی خودسرانه عوض نشده‌اند.
پس از انتشار، https://dayamora.com/favicon-96.png و https://dayamora.com/favicon.ico را باز کنید. در Search Console صفحه اصلی را Test Live URL و Request indexing کنید. آیکون گوگل بلافاصله عوض نمی‌شود؛ بازخوانی آن ممکن است چند روز تا چند هفته طول بکشد و نمایش تضمینی نیست.
این بسته تمام سئوی قبلی، معرفی تصاویر و آیکون را یکجا دارد؛ به جای پچ‌های سئوی قبلی از همین بسته استفاده کنید. مراحل گیت بالای راهنما شامل فایل‌های آیکون هم هست.
