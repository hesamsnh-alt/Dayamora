# اصلاح تصویر لباس در ست‌ساز — نسخهٔ ۱.۲

این بسته شامل نسخهٔ قبلی استودیو مانکن و اصلاح تصاویر آن است؛ داخل پروژهٔ فعلی، کنار package.json استخراج کنید و پوشه‌های هم‌نام را ادغام کنید. فایل‌های برنامهٔ اصلی فروشگاه، سفارش، پرداخت و رنگ‌بندی جایگزین نمی‌شوند. lib/db.cjs و lib/storage.cjs قبلی باید موجود باشند.

## نصب در PowerShell

```powershell
node scripts/install-outfit.cjs
git add .
git commit -m "Use approved transparent garment images in outfit studio"
git push origin main
```

دو جدول لازم روی دیتابیس دایامورا آماده شده‌اند. اگر دیتابیس مستقل دیگری دارید، بعد از تنظیم اتصال همان دایامورا، یک بار `node scripts/init-outfit.cjs` اجرا کنید. این بسته تنظیمات ونترا و ازسامها را تغییر نمی‌دهد. کد هنوز روی Netlify منتشر نشده است؛ push و دیپلوی لازم است.

## چه چیزی اصلاح شد؟

- عکس اصلی و گالری تبلیغاتی هیچ‌وقت به‌عنوان جایگزین تصویر آماده روی مانکن استفاده نمی‌شود.
- برای هر محصول و هر رنگ، تصویر شفاف جداگانه در صفحهٔ /garment-admin.html ثبت می‌شود. لینک «تصاویر فقط لباس» در هدر مدیریت اضافه می‌شود. ورود با حساب مدیر لازم است.
- محصول بدون تصویر آماده برای همان رنگ، پیام مشخص دارد و دکمهٔ افزودن آن غیرفعال است. تصویر رنگ دیگر جایگزین نمی‌شود.
- تصویر شفاف واقعی در مرورگر و سرور کنترل می‌شود؛ PNG مات، مربع سفید، شطرنجی چاپ‌شده و تصویر کاملاً خالی رد می‌شوند. WebP شفاف در مرورگر به PNG تبدیل می‌شود.
- پیش‌نمایش شطرنجی، زمینهٔ سفید و تیره و بزرگ‌نمایی تا سه برابر برای بررسی هاله و لبه‌ها فراهم است. تصویر بدون تأیید مدیر دربارهٔ کامل‌بودن لباس و نبود بدن و پس‌زمینه ثبت نمی‌شود.
- سایز، رنگ و چیدمان در کمد همچنان ذخیره می‌شود. تصاویر نامناسب ست‌های قدیمی روی مانکن پنهان می‌شوند و پیام اصلاح دارند؛ فایل ست از دیتابیس حذف نمی‌شود.

## محدودیت مهم؛ این پچ حذف خودکار پس‌زمینه یا استخراج لباس از شخص نیست

پچ مسیر نمایش عکس نامناسب را می‌بندد و امکان ثبت تصویر آماده و کنترل کیفیت آن را می‌دهد. عکس‌های فعلی فروشگاه در این مرحله به‌صورت دسته‌جمعی برش نخورده‌اند. شفافیت، به‌تنهایی اثبات نمی‌کند تصویر فقط لباس است و لبه‌ها تمیزند؛ بررسی بصری مدیر الزامی است.

برای نتیجهٔ حرفه‌ای، فایل شفاف خود لباس از تأمین‌کننده یا عکس لباس تنها روی زمینهٔ ساده تهیه کنید. استخراج از عکس مدل به جداسازی تخصصی لباس و بازبینی دستی نیاز دارد؛ قسمت پوشیده‌شده زیر مو، دست یا بدن در عکس موجود نیست و بازسازی آن می‌تواند ظاهر واقعی کالا را تغییر دهد. ابزار پاک‌کن یا حذف سفیدی برای تضمین کیفیت همهٔ عکس‌ها مناسب نیست.

فایل نهایی باید PNG یا WebP شفاف، حداکثر ۳ مگابایت و حداکثر ۲۰۴۸ پیکسل در هر بُعد، با حاشیهٔ شفاف باشد. برای ردشدن فایل WEBP مات یا PNG دارای زمینه شطرنجی تعجب نکنید؛ پس‌زمینهٔ چاپ‌شده شفافیت نیست. سفید، مشکی، تور و حاشیه‌های ظریف را روی هر دو زمینه بررسی کنید. روش فعلی لبهٔ لباس را خودکار محو یا کوچک نمی‌کند.

این استودیو ترکیب دوبعدی لباس‌هاست و فیت دقیق بدن یا شبیه‌سازی افت پارچه نیست؛ هزینهٔ API تصویر ندارد. تصویر تبلیغاتی اصلی محصول حفظ می‌شود.

## بررسی

آزمون شفافیت واقعی PNG، فیلترهای سطری تصویر، رد مربع مات، انتخاب مستقل هر رنگ و حفظ اندازه و چیدمان پاس شده است. آزمون یکپارچهٔ شاخهٔ آزمایشی Neon، مجوز مدیر و ممنوعیت ثبت توسط مشتری، ثبت تصویر آماده، جلوگیری از استفادهٔ عکس تبلیغاتی و ذخیرهٔ کمد را بررسی کرده است. آپلود بایت‌ها در این آزمون جایگزین آزمایشی دارد؛ اتصال واقعی فضای عکس سایت پس از دیپلوی باید بررسی شود.
