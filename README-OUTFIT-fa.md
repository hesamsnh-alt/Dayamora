# استودیو مانکن دایامورا — پچ افزایشی

این بسته را داخل پوشهٔ فعلی Dayamora، کنار package.json، استخراج کنید؛ پوشه‌های هم‌نام را ادغام کنید. پروژهٔ فعلی، lib/db.cjs و lib/storage.cjs و تنظیمات قبلی لازم هستند. این بسته جایگزین کل پروژه نیست.

## نصب در PowerShell وی‌اس‌کد

```powershell
cd F:\Dayamora-v1.0-VSCode\Dayamora
node scripts/install-outfit.cjs
git add .
git commit -m "Add mannequin studio and saved wardrobe looks"
git push origin main
```

پس از پایان دیپلوی Netlify، صفحهٔ /stylist.html را باز کنید. نصب‌کننده لینک را به صفحهٔ اصلی، محصول و باشگاه اضافه می‌کند و از فایل‌های تغییرکرده نسخهٔ پشتیبان می‌گیرد. اجرای دوبارهٔ نصب‌کننده لینک تکراری نمی‌سازد. اگر Netlify به این مخزن متصل باشد، push دیپلوی جدید را آغاز می‌کند.

جدول جدید dayamora.outfits در دیتابیس فعلی دایامورا ایجاد شده است. برای نصب روی دیتابیس مستقل دیگری، ابتدا DATABASE_URL همان دایامورا را در محیط تنظیم کنید، سپس یک بار `node scripts/init-outfit.cjs` اجرا کنید. هیچ تنظیم جدید OpenAI یا سرویس تصویر لازم نیست. متغیرهای موجود دیتابیس و ذخیره‌سازی عکس Netlify باید فعال باشند. این بسته تنظیمات سرویس‌های دیگر را تغییر نمی‌دهد.

## قابلیت‌ها

- انتخاب چند محصول از برندهای متفاوت، با سایز و رنگ واقعی ثبت‌شدهٔ محصول.
- مانکن ثابت و چیدمان آزاد؛ جابه‌جایی لباس، مقیاس با حفظ تناسب، چرخش، قرینه، ترتیب و مخفی‌کردن لایه‌ها، بازگشت و انجام دوباره.
- ذخیره در کمد شخصی: نام ست، شناسهٔ محصول، سایز، رنگ، عکس انتخاب‌شده، مختصات و ابعاد، ترتیب لایه‌ها، پس‌زمینه و پیش‌نمایش. ست ذخیره‌شده دوباره با همان انتخاب‌ها باز می‌شود و قابل ویرایش است.
- نمایش ست‌ها در بخش «کمد من» باشگاه؛ ذخیره فقط برای حساب واردشده و دسترسی هر کاربر محدود به ست‌های خودش.
- نگهداری پیش‌نویس در مرورگر، جداگانه برای هر حساب؛ پیش‌نویس مرورگر جای ذخیرهٔ ابری نیست.
- برش مستطیلی، پاک‌کن دستی و حذف سفیدی متصل به لبهٔ عکس؛ تصویر ویرایش‌شده و پیش‌نمایش در فضای خصوصی همان حساب ذخیره می‌شوند.
- خروجی PNG با ابعاد ۱۸۰۰ × ۲۷۰۰؛ حداکثر ۱۶ آیتم در هر ست و ۱۰۰ ست برای هر حساب.

## کیفیت تصویر و اندازه

این ابزار ترکیب لایه‌های دوبعدی روی مانکن است. برای نتیجهٔ تمیز از تصویر روبه‌روی لباس تنها، با پس‌زمینهٔ شفاف استفاده کنید. عکس لباس روی بدن شخص دیگر خودکار جدا یا بازسازی نمی‌شود؛ ابزار آماده‌سازی دستی در ویرایشگر قرار دارد. نمونه‌های تمرینی SVG صرفاً برای یادگیری هستند و محصول قابل خرید محسوب نمی‌شوند.

سایز M یا L انتخاب‌شده ذخیره می‌شود، اما تغییر اندازهٔ تصویر روی مانکن محاسبهٔ اندازهٔ واقعی بدن یا تضمین فیت لباس نیست. ذخیرهٔ ست، سفارش یا رزرو موجودی ایجاد نمی‌کند؛ موجودی هنگام خرید مجدداً بررسی می‌شود.

## بررسی‌های انجام‌شده

آزمون‌های واحد برای حفظ سایز/رنگ/مختصات و رد ورودی نامعتبر؛ آزمون یکپارچه روی شاخهٔ آزمایشی Neon برای ذخیره و بازکردن دقیق، جداسازی حساب‌ها، اعتبارسنجی سایز و رنگ، مالکیت تصویر خصوصی و جلوگیری از بازنویسی نسخهٔ قدیمی پاس شده‌اند. نمای موبایل و دسکتاپ و نصب تکراری بررسی شده‌اند. آپلود واقعی با فضای ذخیره‌سازی سایت آنلاین بعد از دیپلوی باید بررسی شود؛ آزمون خودکار آپلود از جایگزین آزمایشی استفاده می‌کند.

بسته شامل رمز، توکن، فایل محیط یا نسخهٔ قدیمی فایل‌های برنامه نیست. انتشار کد روی GitHub و Netlify هنوز باید با دستورهای بالا انجام شود.
