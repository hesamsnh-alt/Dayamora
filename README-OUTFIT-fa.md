# پچ جداسازی خودکار کالا از عکس — نسخهٔ ۱.۳

این بسته جایگزین پچ قبلی تصاویر ست‌ساز است و استودیو و ذخیرهٔ کمد را هم شامل می‌شود. آن را داخل پروژهٔ فعلی، کنار package.json، استخراج و پوشه‌های هم‌نام را ادغام کنید. فایل‌های برنامهٔ اصلی فروشگاه، سفارش، پرداخت و رنگ‌بندی جایگزین نمی‌شوند. lib/db.cjs و lib/storage.cjs قبلی باید موجود باشند.

## نصب در PowerShell وی‌اس‌کد

```powershell
node scripts/install-outfit.cjs
git add .
git commit -m "Add automatic garment extraction from product photos"
git push origin main
```

بعد از تکمیل دیپلوی Netlify صفحه را با Ctrl+F5 تازه کنید. این پچ هنوز روی سایت شما منتشر نشده است؛ push و دیپلوی لازم است. جدول‌های لازم از قبل روی دیتابیس دایامورا ایجاد شده‌اند؛ دیتابیس و تنظیمات ونترا و ازسامها تغییر نمی‌کنند. برای دیتابیس مستقل دیگری، بعد از تنظیم اتصال همان دایامورا یک بار `node scripts/init-outfit.cjs` اجرا کنید.

## استفاده در ست‌ساز

۱. محصول، رنگ و سایز را انتخاب کنید.
۲. اگر تصویر آماده موجود باشد، مستقیم به ست اضافه می‌شود. در غیر این صورت دکمهٔ «جداکردن خودکار کالا از همین عکس» فعال است؛ دیگر محصول به‌خاطر نبود تصویر آماده به بن‌بست نمی‌رسد.
۳. عکس منبع و نوع کالا را بررسی کنید. برای لباس زیر بالاتنه، نوع مخصوص آن را انتخاب کنید؛ نام «سوتین» به‌صورت پیش‌فرض همین نوع را انتخاب می‌کند.
۴. «شروع جداسازی خودکار» را بزنید. پردازش در مرورگر انجام می‌شود، نه از طریق OpenAI یا API پولی. برای عکس روی شخص هرگز حالت «فقط خود محصول» را انتخاب نکنید؛ آن حالت برای عکس واقعیِ خودِ کالا روی زمینه است.
۵. خروجی را روی زمینهٔ روشن و تیره و با بزرگ‌نمایی بررسی کنید؛ پس از تأیید فقط کالا، آن را به ست اضافه کنید. افزودن قبل از ساخته‌شدن و تأیید خروجی فعال نیست.
۶. ست را در کمد ذخیره کنید؛ همان سایز، رنگ، چیدمان و تصویر برش‌خورده حفظ می‌شوند.

## کنترل کیفیت و حدود واقعی

مدل مخصوص پوشاک از عکس معمولی، لباس را جدا می‌کند؛ پردازش از دو جهت انجام می‌شود تا قسمت‌های بیشتری از لباس حفظ شوند. برای اکسسوری‌های پوشیده‌شده، مدل جداگانهٔ تشخیص لباس/بدن استفاده می‌شود و برای محصولِ تنها مدل حذف پس‌زمینه به‌کار می‌رود. مدل لباس با مدل حذف بک‌گراند معمولی یکسان نیست.

ذرات کوچک جداشده حذف و مرز شفافیت با توجه به لبه‌های خود عکس تنظیم می‌شود؛ بافت و رنگ RGB کالا بازتولید یا نقاشی نمی‌شود. خروجی PNG شفاف است. گزینه‌های پیش‌نمایش و بزرگ‌نمایی برای بررسی هاله، جزئیات بند و پارچه باقی مانده‌اند. هیچ مدل خودکاری برای تمام عکس‌ها برش بی‌نقص تضمین نمی‌کند؛ خروجی بد را تأیید نکنید و از عکس دیگری در گالری استفاده کنید. بخش پوشیده‌شده زیر دست، مو یا بدن بازسازی نمی‌شود.

سوتین/لباس زیر بالاتنه، بالاتنه، شلوار/دامن، پیراهن، کیف، کفش، عینک، کلاه، کمربند و شال پشتیبانی می‌شوند. مدل اختصاصی برای همهٔ جواهرات ریز و همهٔ محصولات فروشگاه وجود ندارد. عکس‌های چندشخصی، لباس خیلی شفاف یا توری، هم‌رنگی پوست و پارچه، پس‌زمینهٔ شلوغ و اجزای پنهان می‌توانند نیازمند انتخاب عکس بهتر یا اصلاح دستی باشند. این ابزار پرو واقعی یا شبیه‌سازی افت پارچه نیست.

## دانلود اول و موبایل

موتورها در اولین استفاده از Hugging Face دانلود می‌شوند و API key یا حساب جدید نمی‌خواهند. مدل لباس حدود ۱۶۸ مگابایت، مدل تشخیص اکسسوری حدود ۶۶ مگابایت و مدل سبک محصولِ تنها حدود ۴٫۴ مگابایت است. فایل‌ها در HTTPS، در صورت پشتیبانی مرورگر و وجود فضا، کش می‌شوند. دانلود و پردازش اول ممکن است چند دقیقه زمان ببرد؛ دکمهٔ توقف وجود دارد. سرعت و حافظهٔ موبایل‌ها متفاوت است و اجرای iPhone به‌صورت واقعی در این محیط آزمایش نشده است.

برای فروشگاه، روش بهتر این است که مدیر یک بار خروجی هر محصول/رنگ را بسازد و تأیید کند تا مشتری‌های بعدی از تصویر آماده استفاده کنند. صفحهٔ /garment-admin.html علاوه بر آپلود فایل شفاف، دکمهٔ جداسازی خودکار از عکس فعلی را هم دارد. ثبت سراسری فقط برای مدیر مجاز است؛ مشتری می‌تواند خروجی شخصی را در ست خودش ذخیره کند.

فایل‌های اجرایی ONNX Runtime داخل پچ هستند؛ وزن مدل‌ها داخل ZIP و Git نیستند و هنگام نیاز از نسخهٔ ثابت دانلود و با SHA-256 بررسی می‌شوند. عکس برای استنتاج به سرویس مدل ارسال نمی‌شود؛ فقط وزن‌های عمومی دریافت می‌شوند. ذخیرهٔ تصویر نهایی و ست، از مسیر ذخیره‌سازی فعلی دایامورا انجام می‌شود. اتصال اینترنت برای دانلود اول لازم است.

## بررسی‌های انجام‌شده

آزمون‌های واحد برای جداسازی برچسب‌های بدن از کالای هدف، پالایش مرز، حذف ذرات، انتخاب نوع کالا، شفافیت واقعی PNG و حفظ رنگ/سایز/مختصات پاس شده‌اند. جداسازی واقعی در مرورگر دسکتاپ، روی بلیزر با زمینهٔ سفید و نمونهٔ لباس زیر روی شخص از کاتالوگ عمومی آزمایش و خروجی روی زمینهٔ تیره بررسی شد. آزمون مرورگر از سرور آزمایشی استفاده می‌کند؛ انتشار واقعی و اتصال آپلود Netlify بعد از push باید بررسی شود. جزئیات مجوز و منابع مدل‌ها در public/segmentation-runtime قرار دارند.
