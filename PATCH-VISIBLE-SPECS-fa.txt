پچ نمایش مشخصات تکمیلی محصول

فقط فیلدهای پرشده جنس، ابعاد، نگهداری، اصالت، ارسال و مرجوعی نمایش داده می‌شوند.
فیلد خالی یا دارای فاصله نمایش داده نمی‌شود. اگر همه خالی باشند، هیچ فهرست خالی و پیام جایگزینی نمایش داده نمی‌شود.
اطلاعات ذخیره‌شده و فرم مدیریت تغییر نمی‌کنند.

فایل public/feature-entry.js را در پوشه همان نام در پروژه جایگزین کنید.
سپس در ترمینال VS Code اجرا کنید:
npm run build
git add public/feature-entry.js
git commit -m "Hide empty product specifications"
git push origin main
