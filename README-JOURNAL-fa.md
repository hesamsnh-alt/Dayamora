# پچ مجله دایامورا — متن و عکس

این پچ برای نسخهٔ گیت 9036565 (Restore measurements and multiple sizes) آماده شده است.
ابتدا از پوشهٔ فعلی پروژه نسخهٔ پشتیبان بگیر. محتویات ZIP را در ریشهٔ پروژه، کنار package.json، کپی و فایل‌های هم‌نام را جایگزین کن. پوشه‌های public و lib باید با پوشه‌های موجود ادغام شوند؛ آن‌ها را حذف نکن.

## ثبت روی گیت و نتلیفای

در PowerShell داخل پوشهٔ پروژه اجرا کن:

```powershell
npm test
npm run build
git add lib/api.cjs lib/journal.cjs package.json public/app.js public/discover.html public/discover.js public/portal.js public/journal-admin.html public/journal-admin.js public/journal-core.js public/journal.css public/journal.html public/journal.js tests/journal.test.cjs README-JOURNAL-fa.md
git commit -m "Add magazine articles with cover and inline photos"
git push origin main
```

اگر نتلیفای به همین مخزن و شاخه متصل است، پس از push دیپلوی جدید را بررسی کن. این ZIP خودش دیپلوی نمی‌کند.

## استفاده

بعد از دیپلوی با حساب مدیر وارد شو: مدیریت فروشگاه ← مدیریت مجله و عکس‌ها ← مقاله جدید.
مسیر مستقیم پنل /journal-admin.html است.

عنوان، دسته و خلاصه را وارد کن. عکس کاور انتخاب کن. با «افزودن متن» و «افزودن عکس» مقاله را بساز. برای عکس‌های داخل متن، توضیح و متن زیر عکس هم قابل ثبت است. ترتیب بخش‌ها با دکمه‌های بالا و پایین تغییر می‌کند.

فرمت تصویر JPG، PNG یا WebP، حداکثر ۳ مگابایت برای هر عکس است. مقاله حداکثر ۴۰ بخش متن/عکس دارد. برای انتشار، کاور و حداقل یک بخش متن لازم است. پیش‌نمایش قبل از ذخیره هم قابل مشاهده است.

«ذخیره پیش‌نویس» مقاله را از فهرست عمومی خارج می‌کند. «انتشار مقاله» آن را در مجله نمایش می‌دهد. «حذف از سایت / بایگانی» حذف دائمی نیست؛ مقاله بایگانی‌شده را می‌توان دوباره ویرایش و منتشر کرد.

منوی مجلهٔ سایت به /discover/journal و کارت هر مقاله به صفحهٔ مستقل آن وصل است.

## ذخیره‌سازی و محدودیت‌ها

از جدول موجود shop_settings و آپلود فعلی فروشگاه استفاده می‌شود؛ SQL جدید، حساب جدید، API جدید یا متغیر محیطی جدید لازم نیست. اتصال فعلی دیتابیس و تنظیمات فعلی آپلود عکس باید فعال باشند. تصاویر آپلودشده عمومی هستند؛ پیش‌نویس مقاله برای بازدیدکنندگان نمایش داده نمی‌شود، اما لینک مستقیم تصویر محرمانه نیست.

این ویرایش، منطق محصولات، سایزها، اندازه‌ها و برندها را تغییر نمی‌دهد. هیچ اتصال یا دادهٔ مربوط به پروژه‌های دیگر تغییر نکرده است.

متن مقاله ساده است و HTML اجرا نمی‌شود. عنوان و توضیح سئو در مرورگر تنظیم می‌شوند؛ مقاله‌ها رندر سمت سرور یا پیش‌رندر مخصوص موتور جست‌وجو ندارند.

## بررسی انجام‌شده

۳۶ تست موفق، ۱ تست اجرا نشده، بدون شکست؛ build موفق. ذخیره، انتشار، کنترل نسخه و بایگانی روی دیتابیس آزمایشی جدا بررسی شد و رکورد آزمایشی پاک شد. نمایش عمومی، عکس کاور، عکس داخل متن، پیش‌نمایش و فرم در عرض موبایل نیز بررسی شدند. آپلود واقعی سرویس ابری در این بررسی انجام نشده؛ همان مسیر آپلود موجود فروشگاه استفاده می‌شود.
