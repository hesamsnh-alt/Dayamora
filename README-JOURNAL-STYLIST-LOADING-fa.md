# اصلاح بازشدن مجله و بارگذاری استایل‌ساز

مبنای پچ: commit 2e80445 از مخزن Dayamora. این پچ تغییرات مجله، بازیابی رمز و ثبت‌نام قبلی را نگه می‌دارد و فایل‌های مدیریت محصول، سایزبندی و دیتابیس را تغییر نمی‌دهد.

## نتیجهٔ بررسی سایت فعلی

دکمهٔ مجله در سایت منتشرشده باز شد و مقالهٔ «۷ راز شیک‌پوشی با هزینه کم» با متن و عکس‌ها نمایش داده شد. ایراد پیدا‌شده این بود که صفحهٔ مجله ابتدا منتظر دریافت کاتالوگ و تصاویر مانکن می‌ماند؛ خرابی یا کندی آن مسیرها می‌توانست مجله را معطل کند.

در استایل‌ساز ۷ محصول دیده شد، ولی پاسخ واقعی /outfit-api/cutouts خالی بود: هیچ تصویر آمادهٔ مانکن برای محصولات فعلی ثبت نشده بود. عکس تبلیغاتی محصول و تصویر شفاف مخصوص مانکن دو فایل متفاوت‌اند. این پچ تصویر جدید برش نمی‌دهد و محصولات فعلی را خودکار آماده نمی‌کند.

## اصلاحات کد

- منوی مجله لینک عادی HTML شده و به اجرای app.js وابسته نیست.
- صفحهٔ مجله مستقل از کاتالوگ، اطلاعات کاربر و تصاویر مانکن بارگذاری می‌شود.
- دریافت محصولات و تصاویر مانکن هم‌زمان آغاز می‌شوند؛ انتظار برای تصاویر، فهرست محصولات را پنهان نمی‌کند.
- شکست دریافت تصاویر دیگر مخفی نمی‌شود؛ دکمهٔ تلاش دوباره اضافه شده است.
- وضعیت آماده‌بودن تصویر هر محصول مشخص است؛ پیام ورود هم فقط وعدهٔ انتخاب محصولات آماده را می‌دهد.
- اگر رنگ اول محصول آماده نباشد، رنگ آمادهٔ دیگری از همان محصول انتخاب می‌شود؛ رنگ آمادهٔ دارای موجودی اولویت دارد.
- لینک آماده‌سازی تصاویر برای مدیر در خود استایل‌ساز نمایش داده می‌شود.

## آماده‌کردن محصولات فعلی — لازم است

۱. با حساب مدیر وارد سایت شو.
۲. از «تصاویر فقط لباس» یا آدرس /garment-admin.html وارد بخش آماده‌سازی شو.
۳. محصول و رنگ را انتخاب کن و جداسازی خود محصول را اجرا کن، یا PNG شفافِ آمادهٔ همان محصول و رنگ را بارگذاری کن.
۴. خروجی را بررسی کن: بدن شخص، پس‌زمینه و بخش‌های اضافی نباید باقی مانده باشند. خروجی نامناسب را ثبت نکن؛ در این حالت عکس مناسب‌تر همان محصول یا فایل شفاف آماده لازم است.
۵. تأیید «فقط لباس» و ثبت را بزن. این کار برای هر رنگ جدا لازم است.
۶. استایل‌ساز را دوباره باز کن؛ محصول ثبت‌شده نشان «آمادهٔ مانکن» می‌گیرد و مشتری فقط روی آن می‌زند.

موتور جداسازی موجود رایگان است و در مرورگر مدیر اجرا می‌شود؛ اولین دریافت مدل می‌تواند حجیم و زمان‌بر باشد. این پچ کیفیت برش را تغییر نمی‌دهد و حذف تمیز بدن شخص از هر عکس تبلیغاتی را تضمین نمی‌کند. افزودن عکس کامل شخص یا مربع عکس اصلی به مانکن به‌عنوان راه میان‌بر انجام نشده است.

## نصب و گیت

قبل از جایگزینی از پروژه نسخهٔ پشتیبان بگیر. محتویات ZIP را در ریشهٔ پروژه کنار package.json کپی کن؛ پوشه‌ها را ادغام و فایل‌های هم‌نام را جایگزین کن. پوشهٔ public را حذف نکن.

```powershell
npm test
npm run build
git add package.json public/index.html public/app.js public/discover.js public/outfit.js public/stylist.html public/cutout-check.js tests/journal-stylist-loading.test.cjs README-JOURNAL-STYLIST-LOADING-fa.md
git commit -m "Fix journal loading and mannequin cutout readiness"
git push origin main
```

پس از دیپلوی موفق نتلیفای، صفحه را با Ctrl+F5 باز کن. این ZIP خودش دیپلوی نمی‌کند. متغیر محیطی یا SQL جدید لازم نیست.

## بررسی

۴۶ تست موفق، ۱ تست دیتابیس ابری اجرا نشده و build موفق. در مرورگر، مجلهٔ اصلاح‌شده و قرارگرفتن لباس آزمایشی با تصویر شفاف موجود روی مانکن تأیید شد. این آزمون روی پیش‌نمایش جدا انجام شد؛ حساب، مقاله، تصویر محصول یا دیتابیس واقعی تغییر نکرد. برش تصاویر محصولات فعلی و ثبت آن‌ها در دیتابیس واقعی انجام نشده است.
