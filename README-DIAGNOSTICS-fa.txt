پچ کوچک تشخیص علت خطای ترجمه

این پچ روی آخرین پچ Automatic-Persian-Importer نصب می‌شود. فقط lib/import-translate.cjs عوض می‌شود؛ دیتابیس، مجله، رابط و سایر امکانات تغییر نمی‌کنند.

فایل lib/import-translate.cjs را داخل پوشه lib پروژه جایگزین کن. فایل تست را هم در tests قرار بده.
در VS Code:
node --test tests/auto-import.test.cjs tests/translation-diagnostics.test.cjs
npm run build
git add lib/import-translate.cjs tests/translation-diagnostics.test.cjs
git commit -m "Show actionable and safe translation errors"
git push origin main
سپس نسخه تازه را در Netlify دیپلوی کن و بررسی لینک را دوباره بزن.

پیام کلی قبلی فقط پاسخ ناموفق را نشان می‌داد؛ از آن نمی‌توان فهمید کلید نامعتبر است یا اعتبار تمام شده است. این پچ کد قابل تشخیص کنار پیام فارسی می‌گذارد:
OPENAI_AUTH_401: احراز هویت رد شده؛ کلید، پروژه و دسترسی را بررسی کن.
OPENAI_ACCESS_403: دسترسی رد شده؛ علت با متن امن توضیح داده می‌شود.
OPENAI_MODEL_404: مدل پیدا نشده یا در دسترس پروژه نیست.
OPENAI_CREDIT_429: پاسخ سرویس مشخصاً تمام‌شدن اعتبار پیش‌پرداخت را اعلام کرده است.
OPENAI_SPEND_429: سقف هزینه پروژه/سازمان پر شده است.
OPENAI_USAGE_429: سقف مصرف مجاز سازمان پر شده است.
OPENAI_QUOTA_429: سهمیه/اعتبار کافی نیست؛ سرویس علت دقیق‌تر نداده است.
OPENAI_RATE_429: محدودیت نرخ درخواست؛ زمان Retry-After رعایت شود.
OPENAI_LIMIT_429: پاسخ ۴۲۹ نوع محدودیت را مشخص نکرده است.
OPENAI_REQUEST_400: قالب یا پارامتر درخواست پذیرفته نشده است.
OPENAI_SERVICE_5xx: خطای سرور سرویس.
OPENAI_TIMEOUT یا OPENAI_CONNECTION: مهلت پاسخ یا ارتباط سرور.

فاصله اضافی ابتدا/انتهای کلید و نام مدل پاک می‌شود. کلید چندخطی یا نام مدل نامعتبر قبل از ارسال درخواست خطای مشخص می‌دهد.
متن خام خطای ارائه‌دهنده به کاربر یا لاگ برنمی‌گردد؛ ممکن است قطعه‌ای از کلید را داشته باشد. فقط دسته خطا و کد HTTP در لاگ ثبت می‌شوند. کلید را در چت ارسال نکن.

این پچ تشخیص خطاست. حساب API یا موجودی آن را تغییر نمی‌دهد و مشکل واقعی حساب از اسکرین‌شات قبلی هنوز معلوم نیست. پس از دیپلوی فقط متن پیام و کد OPENAI_... را گزارش کن. بدون مشاهده کد دلیل، افزایش اعتبار یا تغییر تنظیمات حساب را حدس نزن.

متغیر مدل اختیاری:
DAYAMORA_IMPORT_TRANSLATION_MODEL=gpt-4o-mini
کلید فقط در متغیر سرور:
OPENAI_API_KEY

۱۰ تست ترجمه/فرایند ورود/تشخیص خطا با پاسخ ساختگی موفق شدند؛ کلید واقعی یا حساب زنده آزمایش نشده است. هیچ درخواست ترجمه پولی، پوش، دیپلوی یا تغییر دیتابیس انجام نشده است.
