اصلاح تکمیلی آماده‌سازی خودکار مانکن دایامورا
این پچ روی نسخه دارای کامیت 1d5e1c2 (پچ آماده‌سازی خودکار و گجت‌ها) نصب می‌شود.
فایل‌ها را داخل ریشه پروژه، کنار package.json، جایگزین کنید. کل پروژه را حذف نکنید.

npm run build
git add public/garment-batch.js public/garment-auto.js public/garment-segment.js public/outfit.js public/stylist.html tests/cutout-registry.test.cjs tests/journal-stylist-loading.test.cjs
git commit -m "Improve automatic mannequin preparation and live readiness"
git push origin main

پس از Published شدن نسخه در Netlify، با حساب مدیر وارد /admin یا /stylist شوید و یک تب را باز نگه دارید. صف بدون آپلود دستی و بدون تیک تأیید شروع می‌شود. مشتری پردازش را اجرا نمی‌کند و فقط تصاویر ذخیره‌شده را دریافت می‌کند.
پوشاک، لباس، کفش و کیف موجود در کاتالوگ و رنگ‌های دارای عکس اختصاصی وارد صف می‌شوند؛ سقف ۲۴ مورد مربوط به ابزار دستی است و صف خودکار چنین سقفی ندارد. همه محصولات، حتی غیرفعال‌ها، برای مدیر بررسی می‌شوند؛ مشتری فقط محصولات فعال را می‌بیند.
اگر عکس اصلی برای جداسازی ناموفق باشد، تصاویر تکمیلی همان محصول در محصولات بدون چند رنگ امتحان می‌شوند. برای چند رنگ، گالری مشترک به رنگ دلخواه نسبت داده نمی‌شود و عکس اختصاصی هر رنگ لازم است. خطای دریافت مدل، اتصال، احراز هویت یا محدودیت سرویس به عنوان موفقیت ثبت نمی‌شود.
بارگذاری عکس بعد از ۳۰ ثانیه خطا می‌دهد تا یک عکس خراب برای همیشه کل صف را معطل نکند.
صفحه مانکن هر ۳۰ ثانیه در حالت قابل مشاهده، اگر محصول آماده‌نشده دارد، خروجی‌های تازه را دریافت می‌کند. نیازی به رفرش دستی مشتری برای دیدن تصاویر تازه آماده‌شده نیست.
در صفحه مانکن، مدیر هم پیام پیشرفت/خطای آماده‌سازی را می‌بیند. برای مشتری مدل‌های پردازش دانلود نمی‌شوند.
پردازش همچنان در مرورگر مدیر است؛ با بسته‌شدن تب ادامه نمی‌یابد. این فایل‌ها خود تصاویر آماده‌شده کاتالوگ آنلاین نیستند و ما پردازش روی دیتابیس زنده انجام نداده‌ایم. کیفیت برش تمام عکس‌های واقعی تأیید نشده است؛ تشخیص مدل محلی می‌تواند ناموفق یا نادقیق باشد. هیچ تضمینی برای جداسازی بی‌نقص از همه عکس‌های تبلیغاتی وجود ندارد.
تست: npm test شامل ۱۱۸ موفق و ۱ skip؛ build شامل ۶۸ تست موفق.
