# ثبت‌نام دو مرحله‌ای و رمز دلخواه دایامورا

مبنای پچ: a77d964 (Fix journal loading and mannequin cutout readiness).

## مسیر کاربر

در صفحهٔ ورود، «عضو نیستی؟ حساب بساز» را بزن. مسیر مستقیم ثبت‌نام /club?register=1 است.

مرحلهٔ اول فقط آدرس ایمیل را می‌خواهد. با «ادامه»، مرحلهٔ دوم همان ایمیل را نگه می‌دارد و نام، تلفن، رمز دلخواه دایامورا و تکرار رمز دلخواه را می‌خواهد. برای تغییر ایمیل دکمهٔ جدا وجود دارد.

رمز حداقل ۱۰ و حداکثر ۱۲۸ کاراکتر است و کاربر خودش آن را انتخاب می‌کند. این رمز برای دایامورا است و رمز صندوق ایمیل نیست. اگر دو رمز یکسان نباشند، هم فرم و هم سرور ثبت‌نام را رد می‌کنند. بررسی مرحلهٔ اول فقط اعتبار ظاهری ایمیل است؛ تأیید مالکیت ایمیل انجام نمی‌شود.

پس از ثبت‌نام، رمز با هش ذخیره می‌شود و کاربر وارد حساب می‌شود. برای دفعات بعد ایمیل و همان رمز دایامورا کافی است. ایمیل تکراری حساب جدید نمی‌سازد؛ فرم پیشنهاد ورود یا فراموشی رمز می‌دهد. رمز حساب‌های قبلی تغییری نکرده است.

ورود از سبد خرید نیز به فرم مشترک متصل شده است؛ پس از ورود، کاربر به سبد برمی‌گردد. انتخاب‌های مهمان از مسیر قبلی به حساب منتقل می‌شوند. رمزها در localStorage ذخیره نمی‌شوند.

## فراموشی رمز

دکمهٔ فراموشی رمز، ایمیل واردشده را در فرم بازیابی قرار می‌دهد. مسیر امن موجود، لینک یک‌بارمصرف تعیین رمز جدید را برای همان حساب می‌سازد؛ رمز قبلی قابل مشاهده یا ارسال نیست و اطلاعات حساب پاک نمی‌شود.

ارسال خودکار لینک هنوز به اتصال واقعی سرویس ایمیل نیاز دارد. در نتلیفای این متغیرهای سرور باید با مقادیر معتبر تنظیم باشند:

```text
RESEND_API_KEY=کلید واقعی سرویس
DAYAMORA_MAIL_FROM=Dayamora <no-reply@YOUR_VERIFIED_DOMAIN>
DAYAMORA_SITE_URL=https://dayamora.netlify.app
```

YOUR_VERIFIED_DOMAIN باید دامنهٔ متعلق به خودت و تأییدشده در Resend باشد؛ متن نمونه را عیناً به‌عنوان تنظیم واقعی ثبت نکن. این پچ سرویس یا دامنهٔ ارسال ایمیل ایجاد و تنظیم نمی‌کند. بدون آن، ثبت‌نام و ورود کار می‌کنند، اما ارسال خودکار لینک بازیابی فعال نمی‌شود. مدیر همچنان از پنل مدیریت ← باشگاه مشتریان ← لینک بازیابی رمز می‌تواند لینک خصوصی برای مشتری بسازد؛ فقط پس از احراز هویت آن را به صاحب حساب بده.

## نصب و گیت

ابتدا از پروژه نسخهٔ پشتیبان بگیر. محتویات ZIP را کنار package.json کپی کن؛ پوشه‌های lib، public و tests را با پوشه‌های موجود ادغام و فایل‌های هم‌نام را جایگزین کن. پوشه‌ها را حذف نکن.

```powershell
npm test
npm run build
git add lib/api.cjs public/app.js public/portal.js tests/account-recovery.test.cjs tests/cloud.test.cjs README-SIGNUP-FLOW-fa.md
git commit -m "Add two-step signup with store password confirmation"
git push origin main
```

پس از دیپلوی موفق نتلیفای، با Ctrl+F5 فرم را باز کن. این ZIP خودش سایت را دیپلوی نمی‌کند. تغییر SQL یا نصب وابستگی جدید لازم نیست.
