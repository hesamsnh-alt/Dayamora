این بسته فقط فایل‌های اجرای محلی است و روی نسخه ۱.۰ یا ۱.۱ کار می‌کند.

۱. فایل ZIP را Extract All کنید.
۲. package.json و dev-server.cjs را کنار index.html کپی کنید، در مسیر:
F:\Dayamora-v1.0-VSCode\Dayamora
فایل‌ها نباید داخل پوشه اضافه قرار بگیرند.
۳. در همان ترمینال VS Code بنویسید:
npm run dev
۴. در مرورگر باز کنید:
http://localhost:3000

نیازی به npm install نیست؛ هیچ کتابخانه اضافی ندارد.
برای دیدن تغییرات، فایل را ذخیره و مرورگر را Refresh کنید.
برای توقف: Ctrl+C
این بسته فقط اجرای محلی را اضافه می‌کند؛ امکانات جدید فروشگاهی ندارد.
